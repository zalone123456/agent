本项目是 AI Agent 实习的 Python 学习项目，按学习日保存练习代码，内容涵盖 Python 基础、JSON 文件读写、HTTP 接口请求和大模型调用。
目前完成的 day06 版本是 DeepSeek 命令行聊天助手，通过 OpenAI Python SDK 调用模型，支持连续聊天、查看帮助、清空上下文、手动保存和退出。
助手按最近五轮完整问答管理聊天历史，API 密钥从 DEEPSEEK_API_KEY 环境变量读取；输入与历史管理、模型调用、JSON 保存分别由独立模块负责。
第八天的学习目标是在现有基础上练习读取本地文档、切分文本和保留来源，再手动选择相关片段进行依据资料的问答。
