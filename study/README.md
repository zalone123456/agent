# Python 实习学习记录

记录 Python 基础练习和项目进度。目前完成学习记录统计器的基础功能，以及 JSON 文件保存与读取。按学习日保留代码，后续继续更新本说明。

## 目录结构

```text
study/
├── README.md
└── pyproject/
    ├── day01/    # 基础统计器和环境检查练习
    └── day02/    # 增加 JSON 保存、读取和数据检查
```

## 学习进度

| 阶段 | 内容 |
| --- | --- |
| 第一天 | 输入检查、列表与字典、循环、函数、异常处理、拆分模块，以及 Python 环境和 Git 基础 |
| 第二天 | 文件读写、JSON、手动保存、启动读取、记录格式检查和文件异常处理 |

## 当前项目功能

- 添加学习主题和学习分钟数。
- 查看全部学习记录。
- 统计记录数量、累计时长和各主题学习时长。
- 拒绝空主题和非正整数分钟数。
- 手动将全部记录保存为 JSON，启动时自动读取历史记录。
- 检查读取数据的结构，并处理常见文件异常。

## 运行方式

需要 Python 3.10 或以上版本；仅使用标准库，无需安装第三方依赖。

在 `study` 目录的终端中运行第二天版本：

```bash
python pyproject/day02/main.py
```

也可以在 PyCharm 中选择相应的 Python 解释器，运行 `pyproject/day02/main.py`。

查看第一天版本：

```bash
python pyproject/day01/main.py
```

## 菜单使用

| 输入 | 功能 |
| --- | --- |
| 1 | 添加学习记录 |
| 2 | 查看全部记录 |
| 3 | 查看统计结果 |
| 4 | 保存记录，仅第二天版本提供 |
| 0 | 退出程序 |

第二天版本退出时不会自动保存，请在退出前选择 `4` 手动保存。

## 数据保存与异常处理

第二天的记录文件为 `pyproject/day02/learning_records.json`，路径根据 `main.py` 所在目录确定。每次保存更新全部记录。

记录采用列表中嵌套字典的格式，每条字典只有一组键值对：主题是非空字符串，分钟数是正整数。

```json
[
    {"Python": 45},
    {"Git": 30}
]
```

- 首次启动找不到记录文件时，以空列表开始。
- JSON 损坏、记录格式不正确或其他读取失败时，报错并停止启动，请先检查或备份原文件。
- 保存失败时显示错误原因。

## 主要代码文件

各学习日目录中的 `main.py` 负责菜单和程序入口，`study_log.py` 负责记录操作与统计；第二天还包含保存、读取和数据检查。其他练习文件用于语法练习。
